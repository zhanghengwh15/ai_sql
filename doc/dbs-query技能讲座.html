1. 讲座目标

  1. 理解 DBS、Archery、实例、数据库与 Target 的关系。
  2. 发现当前账号可读资源，先看表结构，再写受限的 SELECT。
  3. 保存可追溯 JSON 快照，并从快照生成批量 SQL。
  4. 正确处理认证失效、目标不唯一和字段不确定。

2. 示例数据

箱装快照包含 material_id、material_code、material_name、measure_unit、unit。千克快照有 1,767 个不同 ID，单位均为“千克”。

{ "material_id": 100001, "material_code": "B010300032", "material_name": "5L*2罐厨邦味极鲜酱油（酿造酱油）（日韩版）", "measure_unit": "箱(2)", "unit": "箱(2)" }
快照是输入证据，不等于写入授权。执行更新前必须核对目标、条件和差异数量。

4. 标准操作流程

4.1 登录态与 Target

DBS=.codex/skills/dbs-query/dbs.py $DBS --compact auth status --site poit $DBS --compact target list --search 美味鲜 $DBS --compact target show meiweixian-prod-material

本例 Target 为 meiweixian-prod-material，对应美味鲜生产 MySQL 的 poit-material 数据库。生产目标必须由操作者确认。

4.2 表结构与环境取证

$DBS --compact desc --target meiweixian-prod-material material $DBS --compact query --target meiweixian-prod-material --table material \ --sql "SELECT VERSION() AS db_version" --limit 1 $DBS --compact query --target meiweixian-prod-material --table material \ --sql "SELECT @@sql_mode AS sql_mode" --limit 1

4.3 查询箱装物料

$DBS --compact query \ --target meiweixian-prod-material --table material \ --columns material_id,material_code,material_name,measure_unit,unit \ --where "rec_status = 1 AND measure_unit LIKE '箱%'" --limit 20

完整快照超过 1,000 行时，按 material_id 做 keyset 分页，把上一页最后一个 ID 代入 material_id > <last_id>。

5. JSON → SQL

5.1 生成规则

  • 读取 material_measure_unit_kilogram.json，去重并升序排列 1,767 个 ID。
  • 只处理 rec_status = 1 且 measure_unit = '千克' 的记录。
  • 同时写入两个单位字段，并使用 null-safe 条件避免无意义重复更新。
-- 产物：center/美味鲜/material_kilogram_unit_to_ton.sql UPDATE `material` SET `measure_unit` = '吨', `unit` = '吨' WHERE `rec_status` = 1 AND `measure_unit` = '千克' AND NOT (`measure_unit` <=> '吨' AND `unit` <=> '吨') AND `material_id` IN (/* 1,767 个快照 ID */);

完整 SQL：material_kilogram_unit_to_ton.sql。

5.2 执行前后核对

SELECT COUNT(*) AS candidate_count FROM `material` WHERE `rec_status` = 1 AND `measure_unit` = '千克' AND `material_id` IN (/* 同一批 ID */); -- 写入后再次执行同一口径，预期 remaining_count = 0
dbs-query 不执行这条 UPDATE。它只负责读取、核对和留下可审计证据。

6. 常见错误

错误含义处理
AUTH_REQUIRED会话失效或返回登录页交互执行 auth login，不把密码写入命令。
TARGET_NOT_FOUNDTarget 名称错误或未配置先搜索并确认候选目标。
QUERY_REJECTED包含写操作、多语句或副作用函数改成单条只读 SELECT。
字段不确定假设与真实表结构不一致先执行 desc。
本次生成时目标列表可见，但实际 desc/query 返回 AUTH_REQUIRED；所以示例快照使用仓库中已保存的 JSON。重新登录后可按上面的命令复现。
